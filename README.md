# Hornet Hacks 🐝
Landing page for **Hornet Hacks**, Sacramento State’s premier student-led hackathon.

## About
Hornet Hacks is the largest hackathon hosted at Sacramento State, designed to bring students together to innovate, collaborate, and showcase their creativity.  
This repository contains the official landing page for the event.
